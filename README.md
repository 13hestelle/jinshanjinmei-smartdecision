# 尽膳尽美｜片区画像智能选品

一个基于成都净菜市场调研报告参数制作的 Streamlit 本地应用。当前版本只保留“智能选品”主功能。

## 功能
- 输入销售点周边居民特征：学生、白领、老年人、年轻租住人群、小家庭/双职工家庭、收入水平和预算特征。
- 选择价格定位、履约能力、销售点规模。
- 生成选品模式、建议价格溢价、销售/配送方式、品质展示和补货建议。
- 使用报告中的属性效用与细分画像权重，对净菜候选组合进行排序，并支持 CSV 导出。

## Windows 运行方式
1. 解压 ZIP。
2. 打开包含 `app.py` 和 `requirements.txt` 的 `jingshan_platform` 文件夹。
3. 点击资源管理器地址栏，输入 `cmd` 并回车。
4. 执行：

```cmd
python -m pip install -r requirements.txt
streamlit run app.py
```

浏览器通常会自动打开；如未打开，请访问终端显示的本地地址（一般为 `http://localhost:8501`）。

## 模型边界
- 有效问卷口径按项目要求统一为 994 份。
- 属性效用与三类消费者画像权重取自调研报告。
- 居民特征到消费画像的映射、配送策略等属于可解释的经营规则，并非报告直接估计的统计系数。
- 平台匹配分是内部相对排序分，不是购买概率、销量或利润预测。
- 报告未提供逐份问卷原始数据或销售点交易数据，因此不能声称重新训练/独立复现 K-means、Logit 等模型，也不生成虚构的销量、库存和利润预测。
